CSAW26 CTF SANDBOX — QUICK REFERENCE
====================================
Paths:  /home/ctfplayer/ctf_files  (challenge files)
        /home/ctfplayer/workspace  (scratch)
User:   ctfplayer (passwordless sudo; pip install <pkg> works)

RECON
  file X            identify file type
  strings -n 8 X    printable strings
  xxd X | head      hex dump (also: hexdump -C)
  binwalk -e X      firmware/embedded extraction
  readelf -a X      ELF headers        objdump -d X   disassembly
  nm X              symbols            ltrace/strace ./X   traces

REVERSE ENGINEERING
  r2 X              radare2: aaa; afl; pdf @main
  ghidra-decompile X [out.c]   headless decompile of all functions
  jadx -d out app.apk          decompile Android apps
  apktool d app.apk            unpack/repackage Android apks

PWN
  python3: from pwn import *   pwntools (remote/process, p64, ROP, asm)
  ROPgadget --binary X        gadget search
  gdb X / gdbserver           debugging (multiarch: 32-bit binaries work)
  checksec --file=X           (pwntools checksec)
  angr, capstone, unicorn     symbolic/disasm/emulation libraries

CROSS-ARCH (ARM)
  qemu-aarch64-static ./chal  run an ARM64 binary (explicit interpreter)
  qemu-arm-static ./chal      run an ARM32 binary
  gdb-multiarch -q ./chal     then: set architecture aarch64; run
  aarch64-linux-gnu-objdump -d X     disassembly (also -R relocs, -s sections)
  aarch64-linux-gnu-gcc -o out x.c   cross-compile
  qemu, gdb-multiarch and aarch64 binutils are preinstalled; do not reinstall them

CRYPTO
  sage -c '...'               SageMath CAS: factor(n), ecm, matrix LLL
  RsaCtfTool -n N -e E --attack all
  cado-nfs N                  number field sieve factoring
  flatter < matrix.txt        fast LLL lattice reduction
  python3: z3 (SMT), Crypto (pycryptodome), sympy, gmpy2, fpylll

FORENSICS / STEGO
  mmls/fls/icat/tsk_recover   Sleuthkit disk images
  foremost -i img -o out      file carving
  testdisk img                partition recovery
  dcfldd if=in of=out hash=md5

  exiftool X                  metadata
  steghide extract -sf X      extract with passphrase
  stegseek X wordlist.txt     brute-force steghide
  zsteg X                     PNG/BMP LSB steg
  pngcheck -v X               PNG structure
  identify/convert X          ImageMagick
  tesseract X.png stdout      OCR
  ffmpeg / sox                audio/video (sox X.wav -n spectrogram -o s.png)
  volatility3 (vol -f mem.raw windows.info)   memory forensics

WEB
  curl -sk https://host:port  HTTP client
  nmap -sV host               port scan
  sqlmap -u URL               SQL injection
  nikto -host URL             web scanner
  python3 -c 'import requests...'   flask for callback servers

MISC
  nc host port                netcat
  socat                       sockets/relays
  grep -r / zsteg / jq / base64 / xxd -r

NOTES
- Sandbox is Linux x86-64: x86/x86-64 binaries run natively; ARM binaries run
  via qemu-aarch64-static (preinstalled).
- Remote challenge services are on the docker network (see challenge target).
- Write generated files under /home/ctfplayer/workspace/.
